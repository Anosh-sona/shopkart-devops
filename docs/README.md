# Shopkart Devops

## Project Description
   A beginner Devops project for monitoring disk usage using bash scripting

## Features
  - Disk usage monitoring
  - Threshold validation
  - Warning messages
  - Log files generation



## How to Run

Run with the default threshold of 80%:

    bash scripts/project_info.sh

Run with a custom threshold of 70%:

    bash scripts/project_info.sh 70
